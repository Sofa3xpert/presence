# Presence packs

Shareable, plain-text content that customises Presence without touching its
code — agent prompt packs, and later interview-sim and assessment-drill packs.
Everything in this directory (formats, schemas, example packs) is
**MIT-licensed** so community packs stay frictionless to share, remix and
redistribute.

Pack format specification lands with milestone M4 (see the v1 plan). Until
then this directory holds the license and this promise: **packs are editable
files in the free core — never paid content.**
