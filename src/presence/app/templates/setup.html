2 · Telegram

Presence talks to you through a bot that is yours alone. Three parts: create the bot once, pair it with your phone, send a test.

A · Create your bot with @BotFather (about two minutes, once)
  1. Open Telegram and find @BotFather: on a phone, scan the code on the right, or tap the link on this device.
  2. Press Start, then send /newbot.
  3. Give it a display name, for example Presence.
  4. Give it a username ending in bot, for example ada_presence_bot. It must be unused.
  5. BotFather replies with a token that looks like 123456789:AAH…. Copy it. On a phone, press and hold the token to copy; if Telegram is on this computer (Telegram Desktop or web.telegram.org) copy and paste directly.
  6. Paste it below and press Save token. Presence checks the token with Telegram before storing it.

The token stays in secrets.env on this machine, readable only by you. Treat it like a password. If it ever leaks, send /revoke to BotFather and save the new one here.
